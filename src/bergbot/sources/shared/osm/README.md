# shared.osm
Amenities near the route from OpenStreetMap via Overpass (ODbL, © OpenStreetMap contributors): alpine huts,
wilderness huts and shelters, restaurants, drinking water and springs, parking, aerialway stations, viewpoints.
Cached 7 days per bbox. OSM `opening_hours` is never used to declare a hut open — status stays `unverified`
until web verification (`shared.web` spec `hut_open`).
