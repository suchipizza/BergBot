# ch.closures
Hiking-trail closures and diversions published by the cantons through SwitzerlandMobility, served on GeoAdmin as
`ch.astra.wanderland-sperrungen_umleitungen`. OGD, © ASTRA / SchweizMobil. Fetched live per audit (1 h cache).
Fields: type (closed/detour), reason and duration in DE/FR/IT/EN, geometry. A closure intersecting the route is
always a `critical` warning; a diversion `important`.
