# ch.hiking_network
Official hiking network: swissTLM3D `Wanderwege` segments (OGD, © swisstopo) and SwitzerlandMobility `Wanderland`
named routes (OGD via ASTRA, © SchweizMobil). Cached 30 days per bbox. Route candidates are subsets of these
segments — no off-network synthesis. `hikingtype` gives a coarse grade hint (Wanderweg → T1, Bergwanderweg → T2,
Alpinwanderweg → T4); the SAC grade is otherwise "not graded".
