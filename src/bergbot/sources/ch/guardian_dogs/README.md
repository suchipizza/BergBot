# ch.guardian_dogs
Alp pastures with livestock guardian dogs (`ch.bafu.alpweiden-herdenschutzhunde`, OGD © BAFU / AGRIDEA).
Cached 7 days. Any intersection with the route (buffered 50 m) is an `important` warning with the standard
behaviour advice from the locale pack; exact dog presence on the day is not verifiable → stays "reported".
