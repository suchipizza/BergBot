# ch.slf
Avalanche bulletin presence and maximum danger level from the SLF CAAML JSON feed. Phase 1 only states *that* a
bulletin exists for the region and its level, with the locked line "Bergbot does not interpret it for hiking"
(SR-4). No data is bundled or re-served; links to slf.ch. Out of season the feed is empty and the report says
"no bulletin published". Full winter handling is Phase 5.
