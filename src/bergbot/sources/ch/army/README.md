# ch.army
Published firing notices (`ch.vbs.schiessanzeigen`, OGD © VBS): danger-zone polygons, weekdays, notice id and
URL. Fetched live per audit. Exact dates/times live on the linked notice page → web verification spec
`shooting_schedule`. Until verified the finding is `shooting_zone` (important); verified activity on the date is
`shooting_activity` (critical, serious register).
