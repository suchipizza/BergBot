# ch.transport
Swiss public-transport timetable through transport.opendata.ch (Open Data Platform Mobility Switzerland).
Stops near a point (cached 7 d), connections and last return (15 min cache, live per audit). Attribution
"© opendata.ch / SBB timetable". Cableway/lift **status** is never taken from the timetable (a scheduled run is
not a verified operating lift) → `lift_unverified` unless web-verified.
