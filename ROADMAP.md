# Roadmap

Phase 1 (this release) ships a complete, daily-usable product for Swiss hiking. Later phases extend, they do not complete.

| Phase | What | Success |
|---|---|---|
| **1 · Launch** ✅ | Plugin marketplace, Telegram (local), Claude Code/Claude.ai plugin, bring-your-own channel, CLI; find · around · audit · check · export · media · help · chat; playful/serious register with mascot; 14 Swiss adapters; single-file mobile report; GPX/KML/GeoJSON; EN/FR/DE/IT; website with install guides; waitlist; tests and benchmark | A first-time user connects Telegram or installs the plugin in < 5 min, asks in their language, gets a warnings-first reply and report, forwards it |
| **2 · Hardening & coverage** | Gold-standard benchmark with founder-verified routes and hard cases; cantonal closure/fire adapters for all cantons; webcam matching; hut/lift verifier quality; report performance on old phones; native-speaker localisation review; season/region-tuned suggestions | Published benchmark pass rate; zero safety regressions in four languages |
| **3 · Messaging** | WhatsApp via a hosted beta bridge (Business API) with a self-host guide; richer Telegram UX; group-chat mode; replanning polish | A WhatsApp-only user completes find → report → GPX without GitHub |
| **4 · Personalization** | Local profile (fitness, home stop, dog, kids); `weekend` workflow with multi-area weather; selected/rejected history; explanations | "What should I do this weekend?" matches the user's habits |
| **5 · Winter & more agents** | SLF bulletin integration, slope/aspect matching, snowshoe and ski-touring routes, stricter winter wording; MTB and trail running; ChatGPT/Codex, Cursor, Gemini, MCP adapters | Bulletin-contextualised ski-tour audit; plugin on ≥ 3 non-Claude agents |
| **6 · Ecosystem** | Adapter SDK, coverage dashboard, freshness/health CI, fixtures generator, contributor docs in four languages | An adapter or region contributed from outside the core team |
| **7 · Business-model validation** | Use waitlist and usage to test hosted convenience, monitoring, marketplace, B2B — or choose not to monetise | Free product untouched in every scenario |
| **8 · Alps and beyond** | Country packs FR/IT/AT/DE/SI on the same contracts, national difficulty scales, local navigation apps | A French user audits a Chamonix route with French official sources |

Open decisions (founder): Claude.ai marketplace path verification · domain and trademark check · WhatsApp bridge operator (Phase 3).
