# Collegare Telegram

Il tuo bot, sulla tua macchina. Nulla è ospitato; il token resta in ~/.bergbot.

**Passo 1 — Crea un bot: apri @BotFather in Telegram, invia /newbot, scegli nome e username, copia il token**

![](../screenshots/connect-tg-1.png)

**Passo 2 — Installa e collega**
```
pipx install "bergbot[all]"
bergbot connect telegram
```
![](../screenshots/connect-tg-2.png)

**Passo 3 — Scrivi al tuo bot: un luogo, un desiderio, o invia un GPX. Tocca un suggerimento per iniziare.**

![](../screenshots/connect-tg-3.png)

Facoltativo: imposta l'avatar in @BotFather → /setuserpic con brand/mascot/dist/avatar.png

## WhatsApp

Onestamente: un bot WhatsApp di Bergbot richiede un account business Meta, un numero dedicato e un webhook pubblico, quindi sarà una beta ospitata (fase 3). Iscriviti alla lista d'attesa. Oggi: Telegram, o il tuo canale tramite il tuo agente.
