# Telegram verbinden

Dein eigener Bot, auf deinem Rechner. Nichts wird gehostet; das Token bleibt in ~/.bergbot.

**Schritt 1 — Bot erstellen: @BotFather in Telegram öffnen, /newbot senden, Name und Benutzername wählen, Token kopieren**

![](../screenshots/connect-tg-1.png)

**Schritt 2 — Installieren und verbinden**
```
pipx install "bergbot[all]"
bergbot connect telegram
```
![](../screenshots/connect-tg-2.png)

**Schritt 3 — Schreib deinem Bot: einen Ort, einen Wunsch, oder schick ein GPX. Tipp auf einen Vorschlag zum Starten.**

![](../screenshots/connect-tg-3.png)

Optional: Avatar in @BotFather → /setuserpic mit brand/mascot/dist/avatar.png setzen
